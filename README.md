# 🦋 Butterfly Collection

A digital collection of butterflies created as a school project.

The website allows users to explore different butterfly species and learn more about their appearance, habitat, diet and interesting facts.

## 🌐 Website

The project can be published using GitHub Pages.

## ✨ Features

- 🦋 Collection of different butterfly species
- 📷 Photos for each butterfly
- 🔎 Search by name, scientific name, family or habitat
- 📖 Detailed information about each species
- 💡 Interesting facts
- 📱 Responsive design for computers, tablets and phones
- 🎨 Clean and modern interface
- ⚡ No database or server required
